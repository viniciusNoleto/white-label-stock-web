# Internacionalização

- Idiomas: `pt-br` (padrão), `es-mx`, `en-us` — arquivos em `src/locales/`. `pt-br` e `es-mx` são tipados por `en-us` (`as typeof enUs`): chave nova entra nos **três**.
- `I18n` (`src/libs/i18n.ts`): instância própria do i18next por app/requisição SSR; `language` é um signal. O idioma fica no cookie `language` (o SSR já renderiza no idioma certo).
- Template: pipe `t` (`TranslatePipe`) — `{{ 'chave' | t }}`, com interpolação `{{ 'chave' | t: { name } }}`.
- TS: `inject(I18n).t('chave')` dentro de `computed` quando o valor precisa acompanhar a troca de idioma (schemas Yup, labels de ações da tabela).
- Mensagens da API chegam como `ApiMessage` e são resolvidas por `resolveApiMessage` (já feito por `injectNotify`).
- Nunca escreva texto visível fixo no template.
